<a id="شروع-کار"></a>

## 🚀 شروع کار

کامپایلر C++ مثل GCC، Clang یا MSVC. دستورهای زیر از g++ استفاده می‌کنند.

<div dir="ltr">

```bash
git clone https://github.com/MOHAMMADREZAABEDINPOOR/c-mn.git
cd c-mn

g++ main.cpp -o words-to-file
./words-to-file
```
