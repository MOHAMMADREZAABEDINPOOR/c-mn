# WORDS TO FILE

برنامه کنسولی C++ که واژه‌ها را می‌خواند و تا ورود exit هر مقدار را در فایل می‌نویسد.

[GitHub](https://github.com/MOHAMMADREZAABEDINPOOR/c-mn) · [PIMX / Profile](https://github.com/MOHAMMADREZAABEDINPOOR) · [بنر ثابت](assets/readme/hero.png)

## امکانات

- ورودی واژه از کنسول
- خروجی با ofstream
- پایان با exit

## پشته فنی

| ابزار | نسخه یا منبع |
|---|---|
| C++ | `standard library` |

## شروع کار

کامپایلر C++ مثل GCC، Clang یا MSVC. دستورهای زیر از g++ استفاده می‌کنند.

```bash
git clone https://github.com/MOHAMMADREZAABEDINPOOR/c-mn.git
cd c-mn

g++ main.cpp -o words-to-file
./words-to-file
```
